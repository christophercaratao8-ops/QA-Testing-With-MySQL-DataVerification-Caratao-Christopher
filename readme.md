# QA Testing with MySQL Data Verification

## Repository Overview

This QAT (Quality Assurance Testing) toolkit documents the functional testing of an AI-generated web application, "Kara David's Wish Note", with backend verification using MySQL queries.

The repository contains three parts:

- **Part A:** This `readme.md` file, containing the test case for the AI-generated web application (the original test case source is `textcase.txt`).
- **Part B:** The AI prompt used to create the test web application, named `webapp-generation-prompt.txt`.
- **Part C:** The single-file PHP web application generated by AI, named `test-webapp.php`.

| Step | Action | Expected Result | Actual Result |

## Test Status

**Status: Failed**

Step i failed. The web application intentionally omits the `Location` column from its `INSERT` statement and from `bind_param()`, so the Location value entered in the form is never saved to the database.
